MATCH STUDIO V2.6.8-F.11 — ÜRETİM ADAYI

HTTPS / PWA:
1. MatchStudio_V268F11_PWA.zip içeriğini HTTPS statik barındırıcınıza yükleyin.
2. ZIP içindeki index.html site kökünde veya aynı alt klasörde olmalı; dosya yollarını değiştirmeyin.
3. Chrome ile adresi açın; menüden Uygulamayı yükle / Ana ekrana ekle seçin.
4. "Çevrimdışı uygulama dosyaları hazır" mesajını bekleyin; uçak modunda kapatıp tekrar açarak doğrulayın.

TELEFONDA YEREL ÇALIŞTIRMA:
1. Termux'u güvenilir F-Droid kaynağından kurun.
2. PWA ZIP'ini İndirilenler/MATCH_STUDIO_TELEFON klasörüne çıkarın.
3. Termux: pkg update && pkg install nodejs -y
4. Termux: termux-setup-storage
5. Termux: cd ~/storage/downloads/MATCH_STUDIO_TELEFON
6. Termux: sh BASLAT_TERMUX.sh
7. Chrome: http://localhost:8911/index.html
